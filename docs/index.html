Transdom

noun — self-hosted software

A translation engine that lives inside your own server, not someone else's API. It reads a web page's rendered text and rewrites it in place, in real time, as the page changes. from trans- (across) + DOM (Document Object Model)

§1

self-hosted

You run the server. You own the data and the cost. No API keys, no per-word billing, no vendor to depend on.

§2

real-time

A page rewritten by a framework, a modal that opens, a list that loads more — Transdom notices and translates it without a second request from you.

§3

open source

MIT licensed, built in the open. Fork it, read it, extend it, or run it exactly as it ships.

Get started

Transdom has two parts, and both are required — the client library has nothing to translate without a server to call.

1

Run the server

A Python service that does the actual translating. Self-hosted, via Docker:

git clone https://github.com/hjdesigner/transdom
cd transdom
docker compose up --build
2

Add the client to your page

Once the server is running, install the library and point it at your server:

npm install transdom
import { Transdom } from "transdom";

const transdom = new Transdom({
  apiUrl: "http://your-server:8000/translate/batch",
  sourceLang: "en",
  targetLang: "pt",
});

transdom.startAutoTranslate();

Full setup, configuration, and self-hosting details are in the README on GitHub.
